FallEstateOnboard SDK

A JavaScript library with the checks behind FallEstateOnboard, the client-onboarding tool for UK estate and letting agents: the AML risk score for a client, the onboarding steps each kind of client needs, the document and Right to Rent tables, and 10 rules-based answers on AML, Right to Rent, deposits, referencing, redress, client money, tenant fees, vulnerable customers, EPCs and sanctions.

It is the FallEstateOnboard page's own code, taken out so a developer, or an AI agent, can call it directly. It supports your process; it is not legal advice, and the risk score is a heuristic your MLRO sets policy on, not a statutory test.

Start here

  1. Install it from GitHub (it is not on the npm registry): 
    npm install github:sjgant80-hub/fallestateonboard-sdk
  2. Import what you need and call it:
    import { newClientRec, assessAmlRisk, getSteps, askT0 } from '@ai-native-solutions/fallestateonboard-sdk';

const client = newClientRec({ clientType: 'buyer' });
client.aml.pepStatus = true; client.aml.sourceOfFunds = 'overseas';
assessAmlRisk(client);   // { grade: 'high', score: 6, reasons: ['PEP', 'sanctions unchecked', 'overseas source'] }
getSteps(client);        // the six steps a buyer needs (tenants get ten)
askT0('when do letting agents need to do CDD?');
  3. Or use it in a browser page with no install: 
    import * as sdk from 'https://sjgant80-hub.github.io/fallestateonboard-sdk/src/index.js';
  4. Pin a commit for production (npm install github:sjgant80-hub/fallestateonboard-sdk#<commit>) so what you tested is what runs.

How it works

  1. Every block in src/onboard.js, the tables and the four functions, is lifted from the FallEstateOnboard page byte for byte, with only the word export added. scripts/parity.mjs reads the published page and fails the build if any block is no longer there.
  2. The AML score adds 3 for a politically exposed person, 1 if sanctions are not yet checked, 3 for a nationality on the page's high-risk list, 1 for rent over £5,000 a month, and 2 for a buyer with overseas funds. 5 or more is high, 2 or more is medium.
  3. A buyer, seller or landlord goes through six steps; a tenant also needs the tenancy, Right to Rent, referencing and deposit steps (ten).
  4. A question is answered by the first rule whose pattern it matches; otherwise there is no answer, rather than a guess.
  5. The tests pin every weight, both grade edges, the £5,000 boundary, every route and every table, and the mutation gate confirms each comparison in the code is tested (19 of 19).

Compliance

The AML answer reflects the Money Laundering Regulations 2017: estate agents carry out CDD on both the buyer and the seller of every sale, whatever the price; letting agents where the monthly rent is €10,000 or more. The deposit answer reflects the Renters' Rights Act 2025 (England, from 1 May 2026). The score itself is a heuristic, not a test set by any regulation.

Risks, answered straight

  • The high-risk nationality list has no source on the page. UK guidance on high-risk third countries is about where a customer is established, and scoring by nationality can raise discrimination questions under the Equality Act 2010. Have your MLRO and legal adviser review this factor before relying on it.
  • The sanctions answer says to report a sanctions match to the NCA. Check the current reporting route (sanctions reporting generally goes to OFSI; suspicious activity reports go to the NCA) before you rely on that sentence.
  • The score is additive and fixed. It does not replace a risk assessment of your business or of a transaction.
  • The rules-based answers are short summaries as at November 2026; the law changes.

The explainer

The page and this SDK run one copy of the onboarding logic. To make that literally true, the page's functions were rewritten once in a form the mutation gate can test (spaced operators), and the SDK lifts those exact bytes. A parity check reads the published page on every push and every week; if anyone edits the page without the SDK, the build goes red.

Repairing the SDK also fixed the product. The page's AML answer said letting agents were in scope at "€10,000 a year" (it is a month); a risk reason read "high rent >TBAk", left by an old automated edit; and the functions threw on a missing record. All three are fixed on the page and here.

Two questions are left open, deliberately and visibly: the nationality list and the sanctions reporting line. They are legal judgments for the people who carry the regulatory responsibility, so they are written up above rather than silently changed.
